# Windows

When I used Windows, I used these files (it's actually just one file).

## `profile.ps1`

Is it too bad to say that this is PowerShell's `.bashrc`? Anyway, it is located in the PowerShell profile directory,
whose path is stored in the `$PROFILE` variable (but is usually at
`C:\Users\username\Documents\PowerShell\Microsoft.PowerShell_profile.ps1`).

I use it to set the prompt/PS1 (with Git branch name inside repositories) and to create some functions and aliases,
mainly for running `.jar` applications.
